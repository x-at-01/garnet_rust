# WeDB 与 Microsoft Garnet 源码映射与转写设计文档

本项目将 Microsoft Garnet 及其底层高性能存储引擎 Tsavorite (FASTER) 转写为基于 Rust 语言与 `compio` (io_uring / IOCP) 原生异步驱动的高性能微模块（Micro-crates）架构体系。

---

## 目录索引

- [全模块 1:1 源码与测试映射总表 (mapping.md)](./mapping.md)：包含所有微模块与 `../garnet/` 对应 C# 文件、测试用例的完整对照关系。
- 各层详细模块映射详见 [mapping.md](./mapping.md)。

---

## 核心架构分层

│                        Layer 7: 服务端守护进程                         │
│             wedb_server (CLI 参数 / YAML 配置 / 指标 / 优雅停机)       │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
┌───────────────────────────────────┴────────────────────────────────────┐
│                    Layer 6: RESP 协议与高性能网络引擎                  │

└───────────────────────────────────┬────────────────────────────────────┘
                                    │
┌───────────────────────────────────┴────────────────────────────────────┐
│                  Layer 5: Redis 富数据结构与事务/PubSub                │
│    wedb_object (对象存储与 TTL)  wedb_ds (Hash/List/Set/ZSet/Stream)   │
│    wedb_txn (乐观锁事务 WATCH/EXEC)  wedb_pubsub (异步广播)  wedb_acl   │

                                    │
┌───────────────────────────────────┴────────────────────────────────────┐

                                    │
┌───────────────────────────────────┴────────────────────────────────────┐
│                 Layer 3: 顶层单机存储引擎与混合日志                     │
